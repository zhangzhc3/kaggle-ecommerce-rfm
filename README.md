# 电商用户行为与人群分层分析

基于 UCI Online Retail II 数据集（2009-12 ~ 2011-12 跨境电商交易记录），完成**数据清洗 → 探索性分析 → RFM 人群分层**全流程，输出可供推广投放圈选使用的客户分群明细。

## 核心数据

| 指标 | 数值 |
|---|---|
| 原始交易记录 | 1,067,371 行 |
| 清洗后保留 | 779,425 行（保留率 73%） |
| 唯一客户数 | 5,878 |
| 唯一订单数 | 36,969 |
| 时间跨度 | 2009-12-01 ~ 2011-12-09（≈2 年） |
| 覆盖国家 | 40+（UK 占 83%） |

## 分析结论

### 1. 销售趋势
- **10-11 月为销售旺季**，2010/10、2011/10、2011/11 为 TOP3 高峰月份，吻合圣诞礼品批发备货周期
- UK 本土贡献 **82.82%** 销售额；海外市场 TOP5：EIRE、Germany、France、Netherlands、Spain

### 2. 业务特征
- 周六订单量近 0，**典型 B2B 批发商作息**
- 下单高峰集中在工作日 10:00-15:00
- **一次性客户占 27.6%**，复购运营是关键增长抓手
- **Top 20% 客户贡献 77.23% 销售额**，经典二八法则在该数据上成立

### 3. RFM 人群分层结果（5878 名客户）

| 群组 | 客户数 | 客户占比 | 销售额占比 | 运营建议 |
|---|---:|---:|---:|---|
| **高价值** | 1,297 | 22.1% | **68.3%** | 核心金主，重点维护与增值 |
| **沉睡** | 1,955 | 33.3% | 23.5% | **召回 ROI 最高**，重点触达 |
| **潜力** | 1,067 | 18.2% | 6.0% | 培育升级为高价值 |
| **流失** | 1,280 | 21.8% | 1.9% | 低成本唤醒或放弃 |
| **其他** | 279 | 4.7% | 0.5% | 常规维系 |

**关键洞察**：高价值与流失群客户数相当（约各 22%），但销售额贡献相差 **36 倍**，差异化运营策略能带来显著 ROI 提升。

## 方法与工具

- **数据清洗**：剔除无客户 ID、退款单、异常价格、重复行；衍生订单金额、时间维度字段
- **RFM 建模**：以数据集最后一天 +1 作为快照日期，对 Recency / Frequency / Monetary 分别进行五分位打分（1-5），按组合规则划分五群
- **工具栈**：Python 3.11、pandas、numpy、matplotlib、seaborn、jupyter；venv 管理项目依赖
